# Membranch web

React + TypeScript + Vite frontend for the Membranch hackathon app.

## Scripts

| Command | What it does |
|---|---|
| `pnpm dev` | Vite dev server on http://localhost:5173 (proxies `/api` to the backend) |
| `pnpm build` | Typecheck (`tsc -b`) then production build to `dist/` |
| `pnpm preview` | Serve the built `dist/` locally |
| `pnpm typecheck` | `tsc -b` only |
| `pnpm lint` | oxlint (the template's linter) |
| `pnpm test` | Vitest, one run, jsdom environment |
| `pnpm gen:api` | Regenerate `src/api/schema.d.ts` from the running backend's `/openapi.json` (backend must be on :8000) |

## Folder map

```
src/
  main.tsx              entry: StrictMode + TanStack QueryClientProvider
  App.tsx               3-column shell: ChatPanel | CommitDag/MemoryCanvas tabs | Scorecard
  index.css             Tailwind v4 (`@import "tailwindcss"`)
  api/
    client.ts           openapi-fetch client typed by schema.d.ts (baseUrl "")
    schema.d.ts         generated by `pnpm gen:api`; placeholder `paths {}` until then
    sse.ts              subscribe(url, onEvent) wrapper around EventSource
  components/           placeholders owned by Person D (see docs/team/person-d-ui.md)
    ChatPanel.tsx, CommitDag.tsx (React Flow + dagre demo), MemoryCanvas.tsx (<falkordb-canvas>),
    ConflictCard.tsx, Scorecard.tsx, WhyPath.tsx
```

`@/` is an alias for `src/` (Vite and tsconfig).

## How the API proxy works

In dev, `vite.config.ts` forwards any request whose path starts with `/api` to
`http://localhost:8000`. The browser only talks to the Vite origin, so there is no CORS
setup and `EventSource` streams (SSE) pass straight through.

The client uses `baseUrl: ""`, so calls like `api.GET("/api/...")` are same-origin.
In production, FastAPI serves `web/dist` on the same origin, so the same relative paths work.
